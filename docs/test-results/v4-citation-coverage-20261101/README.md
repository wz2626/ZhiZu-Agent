## 问题与改动

详细分析此前整份合同只召回 top_k 条候选，示例合同的全局四条为 LAW-721/707/730/705，遗漏维修依据。现在保留整份查询，并按换行和句末标点分组，最多八个相邻片段组；所有视图在一个向量 HTTP 请求内批量处理，然后按权威 ID 合并。最多九个视图、三十二条候选；不是每个句子逐次联网。top_k 用于每个视图；旧 analyze 与 KB 搜索保持单查询行为，HTTP 字段不变。

提示词要求逐项核对候选支持的权利、义务、前提和例外，但不强制填充引用。实际公开 evidence_by_id 仍只包含模型本次引用且实际检索到的权威正文与来源。没有按关键词硬贴条号，也没有扩展703～734范围。前端原有法条组件直接消费结果。
