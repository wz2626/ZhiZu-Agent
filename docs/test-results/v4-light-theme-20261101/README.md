## 修改与视觉复核

1. 全量处理 CSS 变量、硬编码颜色和模板内的颜色类，覆盖输入、法律依据、草稿、条件结果、恢复、错误和处理详情。没有增加外部依赖或 CDN。
2. 合同采用独立纸面；条款解读与任务区标题更明确；风险行增加间距及摘要字号；场景设置、任务页签、参考稿和发送区分清主次。
3. 页签选中态为白底深青绿字；普通文字、辅助说明、数字、法律来源均提高可读性。非风险原句不再全部染成警告色；选中原句仍有青绿定位。
4. 保留号码本机遮蔽告知、独立字数、2000 字就地原因、键盘焦点和既有防呆。没有改动发送、恢复、草稿或计分脚本；与任务前本地快照比较，内联业务脚本逐字相同。
5. 保留用户偏好的琥珀渐变扫光，等待期间持续运行；减少动态模式静止。等待时不再提前显示“0 项风险”。
6. 实测发现浏览器请求 favicon 返回 404，补充内联 SVG 页签图标；随后新浏览器加载检查没有资源 4xx。

真实云调用完成后，又调整了少量标题、行距及非风险原句的颜色；最终截图、静态测试、Day8、Day10 和布局检查均在这些修改后复验。没有为了验证纯展示调整再次消耗模型调用。

## 真实 API 验证（不使用云模型替身）

生产 FastAPI 应用在独立随机本机端口启动，读取现有 `.env`。模型为实际配置的 DeepSeek 官方 `deepseek-flash` 与硅基流动 `BAAI/bge-m3`；没有依赖覆盖或测试路由。出站记录包装器调用原始 HTTP 方法，仅采集供应商、模型、状态与耗时，不改变响应。所有合同、号码和补充事实均为合成测试数据。

| 链路 | 浏览器 HTTP 响应耗时 | 实际结果 |
| --- | ---: | --- |
| 合同分析 | 38.361 秒 | 5 条分析项，2 项风险、3 项说明；来源定位正确 |
| 首次参考稿 | 5.853 秒 | 574 字参考稿与 8 个服务端问题 ID |
| 带回答更新 | 12.155 秒 | 8 条回答按 question_id 绑定，355 字更新稿，260ms 墨显可见 |
| 第 1／2／3 轮固定演练 | 7.73／5.91／6.42 毫秒 | 50 → 75 → 100 分；最终报价档与清单复制正确 |
| 428 预览 | 2.49 毫秒 | 新遮蔽未直接提交；无额外云调用 |
| 旧快照恢复 | 3.33 毫秒 | 同号回放只提交一次，修改后的新文字保留 |

4 次实际云 HTTP 请求均为 200：embedding 0.433 秒，DeepSeek 分析 35.619 秒、首稿 5.830 秒、更新 12.135 秒。浏览器链路耗时含后端编排，不能与单次模型耗时混用。固定演练、428 与恢复阶段云调用为 0。

28 张真实运行截图覆盖本机打码、等待、五条法律依据面板、处理详情、草稿等待、短时墨显、桌面／手机预算超限、采用草稿、定位、按压、三轮结果、最终档、复制及恢复。完整事实记录见 report.json（附件已移至本机归档），供应商调用元数据见 cloud-http.jsonl（附件已移至本机归档）。

恢复测试明确使用故障注入：服务端已提交后，在浏览器端丢弃响应，进入 unknown，再修改当前输入并按旧快照重试。它不是自然出现的超时，也没有用假业务响应替代真实服务。
