## 高度与滚动归属

外层 `#workspace-app` 使用 `position:fixed; inset:0` 跟随有效视口；`#app` 使用四行 Grid：导航、紧凑状态栏、`minmax(0,1fr)` 工作区、底部说明。外壳用 `overflow:clip` 阻止页面成为隐式滚动容器，内容区域贯穿 `min-height:0`，不是只给 body 隐藏滚动条。实测 CSS 200% 重排后也保持视口边界，不使用放大后会继续撑高页面的最小高度。

| 区域 | 滚动／尺寸规则 |
| --- | --- |
| 风险列表 | 固定面板标题与计数，`.risk-items` 独立滚动 |
| 合同 | 固定面板标题和依据范围；`#contract-scroll` 滚动原文、等待或错误；编辑框随余高伸缩，文本仍可在框内滚动 |
| 条款／草稿／结果／恢复 | 共用稳定的 `#task-panel` 滚动容器；草稿和旧快照不再额外套小滚动框 |
| 处理详情 | 非模态底部抽屉，明确高度上限，正文内部滚动；开启不推挤主工作区，Escape 关闭并归还焦点 |
| 导航与底部说明 | 永远留在外层 Grid 的固定行内，不随任何面板滚动 |

普通桌面空状态的编辑、隐私告知、字数、分析按钮和底部说明都在首屏内。矮窗口或高倍放大时允许相关面板滚动，保证完整内容与控件可达，不缩小字号或截掉内容来换取“无滚动”。

中等宽度保留两栏，风险列表成为上方可横向浏览的紧凑区域；手机及窄视口提供“合同提醒／合同／条款与建议（协商任务）”面板切换。只控制显示，不使用 v-if／key 重建 Composer，不丢输入、问题回答、练习状态或面板阅读位置。

本次布局按开发者最新指令执行，替代前版 Spec 00 §7.3 的页面滚动／sticky 跟随以及 §7.4 的流内详情呈现。未擅自编辑 Spec 文件；数据、归属、幂等和安全契约保持不变。

## 与异步状态的接合

- 新增 `activePane` 仅表示窄屏当前面板，与 `workspaceMode`、草稿／谈判 tx 分离。
- 进入协商显式打开任务面板；选择风险显式打开合同并定位。输入框始终是原 DOM 节点。
- 原句定位以 `#contract-scroll` 为可见边界及 IntersectionObserver root。取消旧定位时停止该容器的平滑滚动，继续保留版本、条款、多处匹配与世代校验。
- 隐藏任务面板完成的草稿／结果只登记，不在不可见面板播放到达效果；切回不补播。
- 处理详情不再调用整页 scrollIntoView，开启后聚焦抽屉按钮，关闭后恢复入口焦点。
- 首屏不需要预留空风险栏；独立练习也使用同一高度框架。
