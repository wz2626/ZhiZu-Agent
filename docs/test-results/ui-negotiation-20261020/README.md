## 布局机制与实测

基础模式为自然流。仅在 CSS 视口宽度大于 1100px、高度至少 920px 时评估固定操作区模式；启用后实测正文可视高度不足 220px，或缩放后的面板无法放入视口时，立即降级。操作区高度仅记录，不设 170px 门槛。布局通过 CSS 类切换，不重建输入控件、不重置会话状态。

同一视口尺寸周期内只允许降级；恢复输入框高度不会自动升级，下一次视口尺寸变化才重新评估。这样避免内容变化造成反复切换。尺寸数据只包含布局数值，不记录合同或消息。

| 样例 | 模式 | 面板高 | 操作区高 | 正文可视高 | 说明 |
| --- | --- | ---: | ---: | ---: | --- |
| 1440×1080，初始状态 | 固定 | 760px | 229.45px | 336px | 正向样例，固定模式确已运行 |
| 1440×1080，第五轮后 | 固定 | 760px | 279.14px | 287px | 滚动正文时操作区位置不变 |
| 1440×920 | 自然流 | 992.89px | 237.45px | 561px | 固定模式候选正文仅 198px，故降级；561px 是降级后的自然内容高度 |
| 1440×560/700/800/900 | 自然流 | 992.89px | 237.45px | 561px | 分别验证回应、确认条件及发送按钮可通过滚动到达 |
| 390×844 | 自然流 | 1051.58px | 279.14px | 578px | 单栏，无横向溢出 |

完整数据及决策原因见最终 布局 JSON（历史附件 `browser-day10-attempt05/day10/browser-results.json`，已转本机归档）。自然流的正文高度不是视口内同时显示的高度。

输入框拉高通过 `style.height = '520px'` 再恢复模拟等价几何变化：确认降级、缩回后保持自然流、调整视口后恢复固定模式，并检查 DOM 节点、草稿、隐私确认、正式条件、分数及请求数保持一致。这是几何代理，没有声称物理拖动了原生调整手柄。

200% 放大通过 `document.body.style.zoom = '2'` 产生布局重排，检查自然流降级、内容可达和无横向溢出；这是 CSS 布局缩放代理，未实测系统级或浏览器原生的“仅文字放大”。放大后标题会换行，截图保留真实表现。

## 行为与来源检查

- 点击风险卡后，收起的建议区会重新展开；建议全文和关联条款号与独立合成样例一致。通用辅导语不会遮住具体建议。普通及减少动态效果设置分别验证定位行为。
- 使用真实 CDP 键盘事件，以 Space/Enter 操作折叠区；第二轮以“输入框 → Tab → 隐私确认 → Space → Tab → 发送 → Enter”完成提交。产品未增加快捷键。
- 用常驻建议区 summary 作为焦点锚点，验证成功返回不抢焦点、不自动滚动。待响应期间调整窗口不会重建输入节点或清空交互状态。
- 使用现有协商状态播报点；发送按钮描述仍指向常驻 `negotiation-pending`。没有遗留角色标签及悬空 `aria-controls`。
- 已确认条件和最新成功回应为独立常显块；上一回合快照、预设提醒与自行补充位于默认收起的“更多事项”。“查看本轮结果”只在用户点击时定位回应。
- 页面和 Markdown 均采用“待明确事项／待补信息”总章节，来源分为“预设提醒”和“自行补充（待确认／待核实）”。提醒直接读取接口字段，保留首轮 null 门控，没有在前端复制后端模板常量。
- 复制标题按预先定义的独立期望字符串验证；押金清单（附件已精简） 分列正式条件、预设提醒和自行补充，手动输入的合成号码被遮蔽。
- 拒绝剪贴板后，回退文本框在关闭的折叠区之外，可见、可滚动到达、已聚焦并全选，内容与预期清单一致；保留导出的 epoch/session 防护。
- 三个场景均完成五轮，第六轮按钮禁用且无请求；Critic 失败不改正式条件/分数/轮次；响应丢失后的重试沿用原请求并接受缓存成功结果。
